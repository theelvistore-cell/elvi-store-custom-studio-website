# ELVI Store  Custom Studio Website

A custom fashion order website for LV Store.

## What it does
- Shows the collections, with videos on each card
- Lets customers customize an outfit step by step, or upload their own design
- Saves each design as a Google Doc, with an order code
- Collects contact details through a Google Form

## How it is built
- Plain HTML, CSS, and JavaScript (no frameworks)
- Hosted on Cloudflare Pages, connected to this repository
- Orders are saved by a Google Apps Script in the store's Google account

## Updating the site
Edit the files in this repository and commit. Cloudflare publishes the change automatically.

## Notes
- Keep each video under 25 MB.
- Never put passwords or private keys in this repository.
